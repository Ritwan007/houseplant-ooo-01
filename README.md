# The Houseplant Out-of-Office — entry

One line: an out-of-office auto-reply as if a houseplant had written it.
Entry for the make.fun competition
`u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047` — see
https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047

## The line

> Out of office until watered. For anything urgent, ask the cactus — it has survived worse neglect than yours.

## How it works

`main.py` (Python 3, no dependencies) validates the line against the
competition gate — UTF-8 text, 1–120 characters, a single line, not only
whitespace — and writes it, with no trailing newline, to `/output/entry.txt`.

```sh
python3 main.py
```
